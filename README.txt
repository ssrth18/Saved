SAVED - install as an app

1. Upload everything in this folder (keep the icons folder) to any HTTPS host,
   e.g. a GitHub Pages repo. Keep the file names as they are.
2. Open https://YOUR-SITE/saved.html in Chrome on your phone.
3. Menu (3 dots) > Install app (or Add to Home screen).
4. Once installed, "Saved" shows up in the Share menu, so you can share links straight into it.

Moving your data: your items live in the browser of the place you opened the file from.
In the old copy open Settings > Data > Export backup, then in the installed app use Import backup.

Updating: replace saved.html on the host. Change V="saved-v1" in saved-sw.js to saved-v2 so phones pick it up.
